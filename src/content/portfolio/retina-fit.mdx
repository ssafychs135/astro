<Section n="01" label="Overview">

전문 측정 장비는 비싸고 공간을 차지합니다. RETINA FIT은 그 과정을 **태블릿 하나로 유사하게 모사**해, 안경점이 간단히 도입할 수 있는 측정·피팅 도구입니다.

7인 팀 프로젝트에서 **AR과 측정 엔진을 단독으로 담당**했습니다. 3D 안경 생성 파이프라인, MediaPipe·ArUco 광학 측정, Three.js AR 피팅을 맡았습니다.

</Section>

<Section n="04" label="Defects">

생성 AI를 실제 제품에 붙일 때 드러난 현실 문제 두 건을 해결했습니다. 생성물을 직접 바꾸는 대신 앞뒤 파이프라인을 설계해 제어했습니다.

  <Grid
    cols={2}
    items={[
      { icon: '🫧', n: 'DEFECT 01', title: '렌즈 환각', sub: '렌즈 없는 테에도 모델이 렌즈를 생성' },
      { icon: '🧭', n: 'DEFECT 02', title: '방향 불일치', sub: '생성된 3D가 정면을 향하지 않음' },
    ]}
  />

  <Defect pnum="DEFECT 01" category="Generation Bias" title="모델이 없는 렌즈를 만들어낸다">
    <div slot="summary">
      다른 사물은 흰 배경에서도 잘 추출되는데, 안경만 <b>렌즈가 없는 테에도 임의로 렌즈를 생성</b>했습니다. 이미지 기반 3D 생성 모델이 "안경에는 렌즈가 있다"는 사전 편향을 강하게 학습한 것이 원인입니다.
    </div>
    <ul slot="tech">
      <li>원인: 생성 모델의 강한 사전 편향으로, 입력에 렌즈가 없어도 렌즈를 생성했다.</li>
      <li><b>해결</b>: ComfyUI 생성 워크플로 앞단에 <code>matting</code> 노드를 추가했다.</li>
      <li>배경을 제거해 <b>안경테만</b> Trellis2에 전달했다.</li>
      <li>재학습 대신 전처리로 입력을 정제해 생성 모델의 편향을 보완했다.</li>
    </ul>

    <Toggle heading="렌즈 없는 안경테로 3D 생성" labelOff="매팅 없음" labelOn="ComfyUI matting">
      <div slot="off">
        <Verdict type="fail">렌즈 환각, 없던 렌즈 생성</Verdict>
        <Glasses lens={true} />
        <div class="ts-cap">생성 결과: 렌즈 채워짐</div>
      </div>
      <div slot="on">
        <Verdict type="ok">안경테만 정상 생성</Verdict>
        <Glasses lens={false} />
        <div class="ts-cap">생성 결과: 테만 생성(렌즈 없음)</div>
      </div>
    </Toggle>
  </Defect>

  <Defect pnum="DEFECT 02" category="Registration" title="생성물의 방향이 제각각이다">
    <div slot="summary">
      Trellis2로 생성한 3D 안경은 <b>방향이 정면을 보장하지 않았습니다</b>. AR로 얼굴에 올리려면 안경의 정면과 중심 기준이 필요한데, 생성물은 매번 방향이 달랐습니다.
    </div>
    <ul slot="tech">
      <li>생성물의 방향이 제각각이라 <b>도메인 지식(대칭성)으로 정면과 중앙을 자동 탐지</b>했다.</li>
      <li><code>const forward_flip = mean_z &lt; 0</code> — 안경 다리 평균 Z 부호로 정면 방향을 자동 정규화했다.</li>
      <li>MediaPipe 얼굴 랜드마크의 기준점에 안경 모델을 정렬하고 배치했다.</li>
      <li>임의 방향으로 생성돼도 자동으로 정렬되어 정확히 착용된다.</li>
      <li>생성물의 불일치를 도메인 지식 기반 정규화와 정합으로 해결했다.</li>
    </ul>

    <Flow
      id="retina-flow"
      heading="생성된 3D를 얼굴에 올리기까지"
      nodes={['생성된 3D\n(임의 방향)', '대칭성으로\n정면 탐지', '중심 정렬', 'MediaPipe\n랜드마크 정합', 'AR 피팅 완료']}
      caption="도메인 지식(안경 형태)과 얼굴 기준점을 결합해 임의 생성물도 정확히 착용한다."
    />
  </Defect>
</Section>
